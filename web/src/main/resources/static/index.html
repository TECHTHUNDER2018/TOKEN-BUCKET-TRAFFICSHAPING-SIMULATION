How Real-Time Plotting Works

1. WebSocket Connection: The dashboard establishes a persistent, real-time WebSocket connection to the server (`ws://.../telemetry`). [Waiting...]

2. Server-Side Broadcasting: Every second, the backend reads the current state of the Token Bucket and Leaky Bucket algorithms (Passed/Dropped metrics) and broadcasts a JSON frame to the browser.

Waiting for telemetry data...

3. Client-Side Rendering: Upon receiving the WebSocket message, Javascript updates the stat counters and pushes the new timestamped data points onto the Chart.js line graphs. [Data points rendered: 0]

4. Sliding Window: To maintain performance and visual clarity, the chart enforces a "sliding window" of the most recent 60 seconds of data. As new dots are pushed to the right, the oldest dots are dropped from the left.
